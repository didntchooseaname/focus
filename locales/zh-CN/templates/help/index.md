# Focus 帮助

Focus 可以直接打开一个 Markdown 笔记文件夹（包括 Obsidian 库），无需任何转换。这些页面介绍 Focus 能做什么，以及如何操作。

| 页面 | 内容 |
|---|---|
| [[getting-started\|快速入门]] | 打开库、窗口布局、笔记的视图 |
| [[keyboard-shortcuts\|键盘快捷键]] | 按位置列出的全部快捷键 |
| [[search-syntax\|搜索语法]] | 搜索框的运算符和面板选项 |
| [[slash-menu\|斜杠菜单]] | 输入 `/` 插入格式、块、图表等内容 |
| [[links-and-embeds\|链接与嵌入]] | 双向链接、锚点、嵌入、标签、脚注 |
| [[graph\|图谱]] | 整个库的图谱和局部图谱 |
| [[ai-and-privacy\|AI 与隐私]] | 助手会向 DeepSeek 发送什么，以及如何屏蔽机密信息 |
| [[ops-mode\|Ops 模式]] | 项目、主机、发现项、日志、检查清单 |
| [[connect-an-agent\|连接代理]] | 让 Claude Code 或其他 MCP 客户端处理库中的笔记 |

> [!tip] 阅读这些页面
> 它们是普通的 Markdown 笔记。页面之间的链接和你自己笔记中的链接用法相同：点击打开，Ctrl 加点击在新标签页中打开。
