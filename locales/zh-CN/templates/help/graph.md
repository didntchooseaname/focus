# 图谱

图谱绘制整个库：每篇笔记是一个节点，每条链接是一条边。返回 [[index|帮助]]。

## 完整图谱

它在中央标签页中打开。基于力的布局在后台计算，图谱稳定后会自动停止，所以静止时打开的图谱不占用处理器时间。

- 悬停在节点上：该节点、它的相邻节点及其边会突出显示，其余部分变淡，并显示标题。
- 点击节点打开对应的笔记。拖动节点可以移动它。
- 用滚轮缩放，以指针为中心。拖动背景或使用方向键平移；`+` 和 `-` 缩放，`0` 使整个图谱适应视图，Escape 清除选择。
- 标签的显示取决于缩放级别和节点的链接数量，视图之外的节点不会绘制。

图谱不用颜色表示节点的类型，而用形状：

| 形状 | 节点 |
|---|---|
| 圆形，链接越多越大 | 笔记 |
| 方形 | 标签 |
| 空心圆环 | 指向不存在笔记的链接 |

## 选项与筛选

| 控件 | 作用 |
|---|---|
| 按查询筛选 | 保留匹配查询的笔记，查询的写法与[[search-syntax\|搜索面板]]相同 |
| 文件夹 | 保留部分文件夹中的笔记 |
| 孤立笔记 | 显示或隐藏没有链接的笔记 |
| 显示标签节点 | 为每个标签添加一个方形节点，连接到它的笔记和上级标签 |
| 显示未解析的链接 | 添加圆环节点 |
| 显示附件 | 添加附件文件 |
| 查找节点 | 将视图居中到某篇笔记并高亮它 |
| 力 | 布局的斥力、链接距离和引力 |

位置会在会话之间保留，新笔记会出现在它的相邻节点附近。

## 局部图谱

右侧栏的“链接”标签页绘制当前笔记的邻域，深度为 1 到 3 条链接，并随着你在笔记之间切换而更新。点击节点会打开对应的笔记。

> [!tip] 按主题浏览库
> 打开标签节点：共用同一标签的笔记会聚集在它周围，嵌套标签（`attack/T1558`）则挂在上级标签下。
