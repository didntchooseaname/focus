# 搜索语法

搜索面板在你输入时就会在每篇笔记中查找文本。返回 [[index|帮助]]。

## 搜索词

用空格分隔的词必须全部出现在笔记中。除非搜索词含有大写字母，否则忽略大小写；除非搜索词含有重音符号，否则忽略重音（可在设置中更改）。少于三个字符的搜索词只匹配完整的词。

| 你写的内容 | Focus 找到的内容 |
|---|---|
| `golden ticket` | 同时包含两个词的笔记 |
| `"golden ticket"` | 包含这个精确短语的笔记 |
| `kerberoast OR asreproast` | 包含其中任一个词的笔记 |
| `golden -silver` | 含有 `golden` 且不含 `silver` 的笔记 |
| `(kerberoast OR asreproast) -lab` | 括号用于分组 |
| `/CVE-\d{4}-\d+/` | 两个斜杠之间的正则表达式 |

`OR` 的优先级低于空格：`a b OR c` 表示 `(a and b) or c`。

## 运算符

| 运算符 | 限定范围 | 示例 |
|---|---|---|
| `tag:` | 带有此标签的笔记，包含嵌套标签 | `tag:#red-team` |
| `path:` | 路径包含该文本的笔记 | `path:Certifications` |
| `file:` | 文件名包含该文本的笔记 | `file:index` |
| `title:` | 标题包含该文本的笔记 | `title:Kerberos` |
| `heading:` | 含有包含该文本的标题的笔记 | `heading:Enumeration` |
| `task:` | 含有包含该文本的任务的笔记 | `task:review` |
| `task-todo:`, `task-done:` | 同上，分别只限未完成任务或已完成任务 | `task-todo:report` |
| `prop:` | frontmatter 属性匹配的笔记 | `prop:status=ready` |

运算符作用于它后面的搜索词。未知的运算符（如 `foo:bar`）会按文本搜索，面板会在搜索框下方说明这一点。未闭合的引号或括号也会在那里提示，查询仍会执行。

## 选项与结果

- 搜索框下方有三个开关：区分大小写、全字匹配和正则表达式。开启正则表达式后，搜索框中的全部文本就是一个表达式。
- 排序方式有相关度、路径、最新优先和最早优先。
- 结果按笔记分组。每篇笔记显示标题、所在文件夹和匹配数，并且可以折叠。每一行显示行号和匹配内容。
- 所选行以反色显示匹配内容，其他行以粗体加下划线显示。方向键移动，Enter 在该行打开笔记。
- 每次按键后都会重新运行查询，并取消上一次运行，所以输入时从不需要等待搜索。

## 辅助搜索

有 API 密钥并开启 AI 开关时，对查询按 Enter 会请求模型把它扩展为多个查询，运行这些查询，合并并排序结果，并在列表上方给出带编号引用的简短回答。生成的查询显示为标签块，你可以编辑、移除或添加。发送的内容见 [[ai-and-privacy|AI 与隐私]]。没有密钥或请求失败时，本地结果会保留，并用一行文字说明出了什么问题。

## 在整个库中替换

Ctrl Shift H 会在查询下方添加一个替换框。Focus 逐篇笔记列出每一行修改前后的样子，每篇笔记和每一行都有复选框。在你按下“应用”之前不会写入任何内容。

- 被替换的文本来自查询：其中的普通搜索词；依次写出的多个词则按短语处理；在正则表达式模式下则是整个表达式。`tag:` 等运算符只决定查看哪些笔记。
- 在正则表达式模式下，替换内容中的 `$1` 代表第一个分组。
- 预览之后在磁盘上发生变化的笔记会保持原样，并列在报告中。
- 不是有效 UTF-8 的文件会被排除并计数。
