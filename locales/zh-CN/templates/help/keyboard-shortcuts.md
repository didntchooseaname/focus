# 键盘快捷键

按位置列出的快捷键。同样的列表（包含你修改过的快捷键）位于“设置”的“快捷键”分区。返回 [[index|帮助]]。

## 任何位置

| 快捷键 | 操作 |
|---|---|
| Ctrl K, Ctrl P, Ctrl O | 打开命令面板 |
| Ctrl Shift P | 打开命令面板并显示命令 |
| Ctrl , | 打开设置 |
| Ctrl B | 显示或隐藏左侧栏 |
| Ctrl Alt B | 显示或隐藏右侧栏 |
| Ctrl J | 显示或隐藏底部面板 |
| Ctrl Shift F | 打开搜索面板 |
| Ctrl Shift E | 打开文件树 |
| Ctrl E | 在编辑和阅读之间切换 |
| Ctrl W | 关闭标签页 |
| Ctrl Tab, Ctrl Shift Tab | 下一个标签页，上一个标签页 |
| Ctrl \ | 向右拆分：笔记移到另一组标签页 |
| Alt Left, Alt Right | 在导航历史中后退、前进 |
| Escape | 关闭打开的菜单、命令面板或对话框 |

## 命令面板与列表

| 快捷键 | 操作 |
|---|---|
| Up, Down | 在列表中移动 |
| Enter | 打开 |
| Ctrl Enter | 在新标签页中打开 |
| Escape | 关闭 |

## 源码编辑器

| 快捷键 | 操作 |
|---|---|
| Ctrl B | 粗体 |
| Ctrl I | 斜体 |
| Ctrl Shift X | 删除线 |
| Ctrl Shift C | 行内代码 |
| Ctrl Shift K | 链接 |
| Ctrl Shift H | 标题 |
| Ctrl Shift 8 | 无序列表 |
| Ctrl L | 任务列表 |
| `/` | 斜杠菜单，见[[slash-menu\|斜杠菜单]] |

在源码编辑器中 Ctrl B 是粗体，在其他位置它用于显示或隐藏左侧栏。

## 实时视图

| 快捷键 | 操作 |
|---|---|
| Ctrl Shift M | 打开光标所在块的 Markdown 源码 |

## 搜索面板

面板获得焦点时有自己的快捷键。运算符见[[search-syntax|搜索语法]]。

| 快捷键 | 操作 |
|---|---|
| Up, Down, Page Up, Page Down | 在结果之间移动 |
| Enter | 在所选结果的所在行打开；没有选中项且 AI 已开启时，向助手提问；AI 关闭时，打开第一个结果 |
| Ctrl Enter | 在新标签页中打开 |
| Escape | 先清空搜索框，再交还焦点 |
| Alt C, Alt W, Alt R | 区分大小写、全字匹配、正则表达式 |
| Alt S | 下一种排序方式 |
| Alt H | 显示或隐藏语法帮助 |
| Alt A | 开启或关闭辅助搜索 |
| Ctrl Shift H | 显示或隐藏替换框 |
| Alt T | 在替换预览中，保留或跳过所选的笔记或行 |

## 阅读视图

| 快捷键 | 操作 |
|---|---|
| Ctrl C | 复制所选文本 |
| Ctrl A | 选中整篇笔记 |
| 点击链接 | 打开目标 |
| Ctrl 加点击链接 | 在新标签页中打开目标 |

## 图谱

| 快捷键 | 操作 |
|---|---|
| 方向键 | 平移 |
| `+`, `-` | 放大，缩小 |
| `0` | 使整个图谱适应视图 |
| Escape | 清除所选节点 |
