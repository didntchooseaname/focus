# 链接与嵌入

无论链接写在哪里都会被计入，重命名或移动笔记时，Focus 会保持链接有效。返回 [[index|帮助]]。

## 链接的种类

| 你写的内容 | 含义 |
|---|---|
| `[[Note]]` | 按名称链接到笔记 |
| `[[Note\|text]]` | 同上，显示为 `text` |
| `[[Note#Heading]]` | 链接到笔记的某个标题 |
| `[[Note#^block]]` | 链接到以 `^block` 结尾的块 |
| `[text](folder/note.md)` | Markdown 链接，路径相对于当前笔记 |
| `![[Note]]` | 嵌入：笔记的内容就地显示 |
| `![[Note#Heading]]` | 嵌入其中一节 |
| `![[image.png\|300]]` | 图片，宽 300 像素 |
| `#tag/sub-tag` | 标签；点击会运行 `tag:` 搜索 |

点击链接打开，Ctrl 加点击在新标签页中打开。指向不存在内容的链接以波浪下划线绘制，计为未解析的链接，列在底部面板的“失效链接”下。

## 名称如何解析

Focus 遵循 Obsidian 的规则，按以下顺序：

1. 相对于包含该链接的笔记的路径；
2. 从库根目录开始的路径；
3. 无论位于何处，唯一一个同名文件；
4. 笔记 frontmatter 中声明的别名。

如果都不匹配，链接就是未解析的。

## 正文之外的链接

链接在所有可以书写的位置都会被识别：

- 正文、标题、列表、表格、提示框、脚注和图片说明；
- frontmatter 属性，作为值（`related: "[[Note]]"`）或出现在列表中。在阅读视图中，属性显示为标签块，其中的链接可以点击；
- Mermaid 图表，在节点标签中（`A["See [[Note]]"]`，显示时不带方括号）或使用 click 指令（`click A "[[Note]]"`）。

在 HTML 导出中，带链接的图表节点是一个链接。阅读视图暂不绘制可点击的图表节点。

以上这些都会计入反向链接、出链、图谱和 MCP 工具。重命名或移动笔记时，Focus 会改写其他笔记中指向它的链接（可在“设置”的“文件与链接”中关闭），其附件所在的子文件夹也会随之移动。

## 脚注

在正文中写 `[^1]`，并在单独一行写 `[^1]: the note`。无论你选了什么标签，引用都按出现顺序编号。悬停在引用上会显示脚注，点击会跳到脚注，脚注中的箭头可以返回。

## 属性、标签和注释

- 两行 `---` 之间的 frontmatter 在阅读视图中显示为笔记顶部的标签块。
- `%% text %%` 是注释：阅读时隐藏，保留在文件中。
- `==text==` 表示高亮。

> [!note] 提示框
> 以 `[!note]`、`[!warning]` 等 Obsidian 类型开头的引用会被绘制为提示框。`[!note]+` 使其可折叠且默认展开，`[!note]-` 使其可折叠且默认折叠。这个框就是一个提示框。
