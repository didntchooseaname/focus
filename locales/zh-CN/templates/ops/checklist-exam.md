# 考试流程

## 考前
- [ ] 完整阅读官方规则
- [ ] 记下开始时间和结束时间，包括时区
- [ ] 检查工作站、网络连接和电源
- [ ] 准备好报告模板
- [ ] 准备好项目文件夹和自动备份
- [ ] 安排好用餐、休息和睡眠

## 时间管理
- [ ] 开始时确定评分方式和作答顺序
- [ ] 为每个目标设定时间上限
- [ ] 每过三分之一的时长设一个检查点
- [ ] 定时休息
- [ ] 实操阶段的末尾留出时间复查证据

## 所需证据
- [ ] 从规则中抄下每个目标所需的证据清单
- [ ] 取得证据后立即截图留存
- [ ] 每张截图上都能看到日期和时间
- [ ] 检查证据内容是否清晰可辨
- [ ] 按目标存放证据

## 备份
- [ ] 每完成一个目标就备份笔记
- [ ] 在工作站之外保留文件夹的副本
- [ ] 日志中及时记录每一步的时间

## 报告
- [ ] 报告结构遵循考官的要求
- [ ] 每个已完成的目标都描述到内行读者能够复现
- [ ] 截图已编号并在正文中引用
- [ ] 说明未完成的目标及已尝试的方法
- [ ] 检查文件格式和文件名
- [ ] 发送前记录文件校验值
- [ ] 在截止时间前确认提交成功

## 考后
- [ ] 关闭考试环境的访问权限
- [ ] 按规则删除考试数据
- [ ] 更新项目状态
