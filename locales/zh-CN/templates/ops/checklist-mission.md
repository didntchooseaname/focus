# 项目流程

## 范围界定与授权
- [ ] 已收到并归档委托书或书面协议
- [ ] 已与客户重述并确认目标
- [ ] 已阅读交战规则：时间段、禁止的操作、紧急联系人
- [ ] 已确定发生事故时要通知的人，并测试过联系方式
- [ ] 已约定数据的保留和销毁方式

## 范围
- [ ] 已书面收到包含项的清单
- [ ] 已书面收到排除项的清单
- [ ] 已与客户核实这些项目的归属
- [ ] 已识别相关第三方（托管方、服务商），必要时已通知
- [ ] 已将范围抄入项目的 README

## 信息收集
- [ ] 开始前列出信息来源
- [ ] 每条观察都记录在日志中并注明目标
- [ ] 将发现的项目对照范围：范围内、范围外或待确认
- [ ] 记下并发出给客户的问题

## 分析
- [ ] 列出候选发现项及支持它们的观察
- [ ] 每个发现项已确认，或标记为待确认
- [ ] 已说明严重程度和评分向量的依据
- [ ] 每个发现项都附上受影响的项目

## 证据与时间戳
- [ ] 每个发现项有一份证据，无需口头解释即可看懂
- [ ] 每份证据上都能看到日期和时间，或与日志关联
- [ ] 证据以固定的名称存放在项目文件夹中
- [ ] 准备放入报告的截图已屏蔽敏感数据
- [ ] 项目文件夹已备份

## 清理
- [ ] 已列出项目期间创建的内容
- [ ] 已删除创建的内容，或连同清单移交给客户
- [ ] 已关闭临时访问权限
- [ ] 项目结束后，工作站上已不再有客户数据

## 汇报与报告
- [ ] 已撰写执行摘要
- [ ] 发现项已按严重程度排序
- [ ] 已为每个发现项撰写修复建议
- [ ] 由第二人复核
- [ ] 已通过约定的渠道交付报告
- [ ] 已安排汇报会议
- [ ] 项目状态已设为已完成
