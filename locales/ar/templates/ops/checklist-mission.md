# سير عمل المهمة

## تحديد النطاق والتفويض
- [ ] استلام خطاب المهمة أو الاتفاق الكتابي وأرشفته
- [ ] إعادة صياغة الأهداف والتحقق منها مع العميل
- [ ] قراءة قواعد الاشتباك: الأوقات والإجراءات المحظورة وجهات الاتصال في الطوارئ
- [ ] تحديد الشخص الذي يجب إبلاغه عند وقوع حادث، واختبار طريقة الوصول إليه
- [ ] الاتفاق على مدة الاحتفاظ بالبيانات وإتلافها

## النطاق
- [ ] استلام قائمة العناصر المشمولة كتابيًا
- [ ] استلام قائمة العناصر المستبعدة كتابيًا
- [ ] التحقق من ملكية العناصر مع العميل
- [ ] تحديد الأطراف الثالثة المعنية (الاستضافة والمزوّد) وإبلاغها عند الحاجة
- [ ] نسخ النطاق إلى ملف README الخاص بالمهمة

## الجمع
- [ ] سرد مصادر المعلومات قبل البدء
- [ ] تسجيل كل ملاحظة في السجل مع هدفها
- [ ] مطابقة العناصر المكتشفة مع النطاق: داخل أو خارج أو قيد التأكيد
- [ ] تدوين أسئلة العميل وإرسالها

## التحليل
- [ ] سرد الاكتشافات المحتملة مع الملاحظات التي تدعمها
- [ ] تأكيد كل اكتشاف أو وسمه بأنه قيد التأكيد
- [ ] تبرير الخطورة ومتجه الدرجة
- [ ] إرفاق العناصر المتأثرة بكل اكتشاف

## الأدلة والطوابع الزمنية
- [ ] دليل واحد لكل اكتشاف، مقروء دون شرح شفهي
- [ ] ظهور التاريخ والوقت في كل دليل أو ربطه بالسجل
- [ ] حفظ الأدلة في مجلد المهمة بأسماء ثابتة
- [ ] إخفاء البيانات الحساسة في لقطات الشاشة المخصصة للتقرير
- [ ] أخذ نسخة احتياطية من مجلد المهمة

## التنظيف
- [ ] سرد العناصر المنشأة أثناء المهمة
- [ ] حذف العناصر المنشأة أو تسليمها للعميل مع القائمة
- [ ] إغلاق الوصول المؤقت
- [ ] إزالة بيانات العميل من محطات العمل بعد إغلاق المهمة

- [ ] كتابة التوصيات لكل اكتشاف
- [ ] مراجعة من شخص ثانٍ
- [ ] تسليم التقرير عبر قناة متفق عليها
