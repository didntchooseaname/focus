# اختصارات لوحة المفاتيح

الاختصارات حسب الموضع. القائمة نفسها، مع الاختصارات التي غيّرتها، موجودة في الإعدادات، قسم الاختصارات. للعودة إلى [[index|المساعدة]].

## في كل مكان

| الاختصار | الإجراء |
|---|---|
| Ctrl K, Ctrl P, Ctrl O | فتح لوحة الأوامر |
| Ctrl Shift P | فتح لوحة الأوامر على الأوامر |
| Ctrl , | فتح الإعدادات |
| Ctrl Shift B | إظهار الشريط الأيسر أو إخفاؤه |
| Ctrl Alt B | إظهار الشريط الأيمن أو إخفاؤه |
| Ctrl J | إظهار اللوحة السفلية أو إخفاؤها |
| Ctrl Shift F | البحث في الخزنة، مع التركيز في حقل البحث |
| Ctrl Shift E | فتح شجرة الملفات، مع التركيز على الملاحظة المفتوحة |
| Ctrl E | التبديل بين القراءة والعرض الذي حُرّرت فيه الملاحظة |
| Ctrl W | إغلاق علامة التبويب |
| Ctrl Tab, Ctrl Shift Tab | علامة التبويب التالية، السابقة |
| Ctrl \ | تقسيم إلى اليمين: تنتقل الملاحظة إلى مجموعة علامات التبويب الأخرى |
| Alt Left, Alt Right | رجوع، تقدم في سجل التنقل |
| Escape | إغلاق القائمة أو اللوحة أو مربع الحوار المفتوح |
| Ctrl N | ملاحظة جديدة يُكتب اسمها فورًا؛ ينقل Enter إلى نصها |
| Ctrl S | حفظ الملاحظة الآن |
| Ctrl Shift T | إعادة فتح علامة التبويب المغلقة |
| Ctrl Page Down, Ctrl Page Up | علامة التبويب التالية، السابقة |
| Ctrl 1 إلى Ctrl 8, Ctrl 9 | علامة التبويب بهذا الترتيب، آخر علامة تبويب |
| Ctrl F, Ctrl H | البحث، البحث والاستبدال في الملاحظة |
| F3, Shift F3 | التطابق التالي، السابق لشريط البحث |
| F6, Shift F6 | نقل التركيز إلى المنطقة التالية، السابقة: الملاحظة، الشريط الأيسر، الشريط الأيمن، اللوحة السفلية |
| Ctrl =, Ctrl -, Ctrl 0 | تكبير الواجهة، تصغيرها، العودة إلى 100 % (وكذلك Ctrl مع عجلة الفأرة) |
| F11 | ملء الشاشة |
| F1, Ctrl / | اختصارات لوحة المفاتيح في الإعدادات |
| Ctrl Q | إنهاء |

## لوحة الأوامر والقوائم

| الاختصار | الإجراء |
|---|---|
| Up, Down | التنقل في القائمة |
| Enter | فتح |
| Ctrl Enter | فتح في علامة تبويب جديدة |
| Escape | إغلاق |

## محرر المصدر

| الاختصار | الإجراء |
|---|---|
| Ctrl B | خط عريض |
| Ctrl I | خط مائل |
| Ctrl Shift X | خط يتوسطه خط |
| Ctrl Shift C | شيفرة ضمن السطر |
| Ctrl Shift K | رابط |
| Ctrl Shift H | عنوان |
| Ctrl Shift 8, Ctrl * | قائمة نقطية |
| Ctrl L | قائمة مهام |
| Tab, Shift Tab | إزاحة عنصر القائمة، إلغاء إزاحته |
| Ctrl Z, Ctrl Shift Z, Ctrl Y | تراجع، إعادة |
| Ctrl Shift V | اللصق كنص عادي |
| Shift Page Up, Shift Page Down | التحديد بالصفحة |
| Shift F10, Menu | القائمة السياقية عند المؤشر |
| `/` | قائمة الشرطة المائلة، انظر [[slash-menu\|قائمة الشرطة المائلة]] |

يجعل Ctrl B النص عريضًا في التحرير وفي Live؛ ولا يفعل شيئًا في القراءة.

## لوحة البحث

للوحة اختصاراتها الخاصة ما دامت تملك التركيز. العوامل مشروحة في [[search-syntax|صيغة البحث]].

| الاختصار | الإجراء |
|---|---|
| Up, Down, Page Up, Page Down | التنقل بين النتائج |
| Enter | فتح النتيجة المحددة عند سطرها؛ وإن لم يكن هناك تحديد والذكاء الاصطناعي مفعّل، يُسأل المساعد؛ وإن كان معطّلًا، تُفتح النتيجة الأولى |
| Ctrl Enter | فتح في علامة تبويب جديدة |
| Escape | مسح الحقل، ثم إعادة التركيز |
| Alt C, Alt W, Alt R | مطابقة حالة الأحرف، كلمة كاملة، تعبير نمطي |
| Alt S | ترتيب الفرز التالي |
| Alt H | إظهار تعليمات الصيغة أو إخفاؤها |
| Alt A | تشغيل البحث بمساعدة الذكاء الاصطناعي أو إيقافه |
| Ctrl Shift H | إظهار حقل الاستبدال أو إخفاؤه |
| Alt T | في معاينة الاستبدال، إبقاء الملاحظة أو السطر المحدد أو تخطيه |

## عرض القراءة

| الاختصار | الإجراء |
|---|---|
| Ctrl C | نسخ النص المحدد |
| Ctrl A | تحديد الملاحظة كلها |
| Ctrl F, Ctrl H | البحث، البحث والاستبدال: تعرض الملاحظة مصدرها ما دام الشريط مفتوحًا وتعود إلى القراءة عند التطابق حين يُغلق |
| النقر على رابط | فتح الهدف |
| Ctrl مع النقر على رابط | فتح الهدف في علامة تبويب جديدة |

## الرسم البياني

| الاختصار | الإجراء |
|---|---|
| مفاتيح الأسهم | تحريك العرض |
| `+`, `-` | تكبير، تصغير |
| `0` | عرض الرسم كله في المساحة المرئية |
| Escape | مسح العقدة المحددة |
