# مساعدة Focus

يفتح Focus مجلدًا من ملاحظات Markdown، بما في ذلك خزنة Obsidian، ويعمل عليه دون تحويل أي شيء. تصف هذه الصفحات ما يفعله Focus وكيفية التحكم فيه.

| الصفحة | محتواها |
|---|---|
| [[getting-started\|البدء]] | فتح خزنة، تخطيط النافذة، طرق عرض الملاحظة |
| [[keyboard-shortcuts\|اختصارات لوحة المفاتيح]] | كل الاختصارات، حسب الموضع |
| [[search-syntax\|صيغة البحث]] | عوامل حقل البحث وخيارات اللوحة |
| [[slash-menu\|قائمة الشرطة المائلة]] | إدراج التنسيق والكتل والمخططات وغيرها بكتابة `/` |
| [[links-and-embeds\|الروابط والتضمين]] | الروابط الداخلية، المراسي، التضمين، الوسوم، الحواشي |
| [[graph\|الرسم البياني]] | الخزنة كاملة في رسم بياني، والرسم البياني المحلي |
| [[ai-and-privacy\|الذكاء الاصطناعي والخصوصية]] | ما يرسله المساعد إلى DeepSeek وكيف تُحجب الأسرار |
| [[ops-mode\|وضع Ops]] | المهام والمضيفون والاكتشافات والسجل وقوائم التحقق |
| [[connect-an-agent\|ربط وكيل]] | السماح لـ Claude Code أو لعميل MCP آخر بالعمل على الخزنة |

> [!tip] قراءة هذه الصفحات
> هذه الصفحات ملاحظات Markdown عادية. الروابط بينها تعمل مثل الروابط في ملاحظاتك: انقر للفتح، أو اضغط Ctrl مع النقر للفتح في علامة تبويب جديدة.
