# Raccourcis clavier

Les raccourcis par endroit. La même liste, avec ceux que vous avez changés, est dans les réglages, section Raccourcis. Retour à [[index|l'aide]].

## Partout

| Raccourci | Action |
|---|---|
| Ctrl K, Ctrl P, Ctrl O | ouvrir la palette |
| Ctrl Maj P | ouvrir la palette sur les commandes |
| Ctrl , | ouvrir les réglages |
| Ctrl B | afficher ou masquer la barre gauche |
| Ctrl Alt B | afficher ou masquer la barre droite |
| Ctrl J | afficher ou masquer le panneau du bas |
| Ctrl Maj F | ouvrir le panneau de recherche |
| Ctrl Maj E | ouvrir l'arbre des fichiers |
| Ctrl E | alterner entre édition et lecture |
| Ctrl W | fermer l'onglet |
| Ctrl Tab, Ctrl Maj Tab | onglet suivant, onglet précédent |
| Ctrl \ | scinder à droite : la note passe dans l'autre groupe d'onglets |
| Alt Gauche, Alt Droite | précédent, suivant dans l'historique de navigation |
| Échap | fermer le menu, la palette ou la boîte de dialogue ouverts |

## Palette et listes

| Raccourci | Action |
|---|---|
| Haut, Bas | se déplacer dans la liste |
| Entrée | ouvrir |
| Ctrl Entrée | ouvrir dans un nouvel onglet |
| Échap | fermer |

## Éditeur de source

| Raccourci | Action |
|---|---|
| Ctrl B | gras |
| Ctrl I | italique |
| Ctrl Maj X | barré |
| Ctrl Maj C | code en ligne |
| Ctrl Maj K | lien |
| Ctrl Maj H | titre |
| Ctrl Maj 8 | liste à puces |
| Ctrl L | liste de tâches |
| `/` | menu « / », voir [[slash-menu\|Le menu « / »]] |

Dans l'éditeur de source Ctrl B met en gras ; ailleurs il bascule la barre gauche.

## Vue Live

| Raccourci | Action |
|---|---|
| Ctrl Maj M | ouvrir la source Markdown du bloc qui contient le curseur |

## Panneau de recherche

Le panneau a ses propres raccourcis tant qu'il a le focus. Les opérateurs sont dans [[search-syntax|Syntaxe de recherche]].

| Raccourci | Action |
|---|---|
| Haut, Bas, Page haut, Page bas | se déplacer entre les résultats |
| Entrée | ouvrir le résultat sélectionné à sa ligne ; sans sélection et avec l'IA active, interroger l'assistant ; avec l'IA désactivée, ouvrir le premier résultat |
| Ctrl Entrée | ouvrir dans un nouvel onglet |
| Échap | vider le champ, puis rendre le focus |
| Alt C, Alt W, Alt R | respecter la casse, mot entier, expression régulière |
| Alt S | ordre de tri suivant |
| Alt H | afficher ou masquer l'aide de syntaxe |
| Alt A | activer ou désactiver la recherche assistée |
| Ctrl Maj H | afficher ou masquer le champ de remplacement |
| Alt T | dans un aperçu de remplacement, garder ou écarter la note ou la ligne sélectionnée |

## Vue de lecture

| Raccourci | Action |
|---|---|
| Ctrl C | copier le texte sélectionné |
| Ctrl A | sélectionner toute la note |
| Clic sur un lien | ouvrir la cible |
| Ctrl clic sur un lien | ouvrir la cible dans un nouvel onglet |

## Graphe

| Raccourci | Action |
|---|---|
| Flèches | déplacer la vue |
| `+`, `-` | zoomer, dézoomer |
| `0` | ajuster tout le graphe à la vue |
| Échap | désélectionner le nœud |
