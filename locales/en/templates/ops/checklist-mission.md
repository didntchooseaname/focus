# Engagement workflow

## Scoping and authorization
- [ ] Engagement letter or written agreement received and archived
- [ ] Objectives restated and validated with the client
- [ ] Rules of engagement read: hours, forbidden actions, emergency contacts
- [ ] Person to notify in case of an incident identified, and a way to reach them tested
- [ ] Data retention and destruction agreed

## Scope
- [ ] List of included items received in writing
- [ ] List of excluded items received in writing
- [ ] Ownership of the items checked with the client
- [ ] Third parties involved (host, provider) identified and notified if needed
- [ ] Scope copied into the README of the engagement

## Collection
- [ ] Information sources listed before starting
- [ ] Each observation recorded in the journal with its target
- [ ] Discovered items matched to the scope: inside, outside or to confirm
- [ ] Questions for the client noted and sent

## Analysis
- [ ] Candidate findings listed with the observations that support them
- [ ] Each finding confirmed, or marked as to confirm
- [ ] Severity and score vector justified
- [ ] Affected items attached to each finding

## Evidence and timestamps
- [ ] One piece of evidence per finding, readable without verbal explanation
- [ ] Date and time visible on each piece of evidence or tied to the journal
- [ ] Evidence stored in the engagement folder under stable names
- [ ] Sensitive data masked in the screenshots meant for the report
- [ ] Engagement folder backed up

## Cleanup
- [ ] Items created during the engagement listed
- [ ] Created items removed, or handed to the client with the list
- [ ] Temporary access closed
- [ ] Client data gone from the workstations once the engagement is closed

## Debrief and report
- [ ] Executive summary written
- [ ] Findings sorted by severity
- [ ] Recommendations written for each finding
- [ ] Review by a second person
- [ ] Report delivered through an agreed channel
- [ ] Debrief meeting scheduled
- [ ] Engagement status set to done
