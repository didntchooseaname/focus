# Exam workflow

## Before the exam
- [ ] Official rules read in full
- [ ] Start time and end time noted, time zone included
- [ ] Workstation, connection and power checked
- [ ] Report template prepared
- [ ] Engagement folder and automatic backup ready
- [ ] Meals, breaks and sleep planned

## Time management
- [ ] Scoring and order of work decided at the start
- [ ] Time limit set for each objective
- [ ] Checkpoint at each third of the duration
- [ ] Breaks taken at regular intervals
- [ ] End of the practical work reserved for reviewing evidence

## Required evidence
- [ ] List of evidence required per objective copied from the rules
- [ ] Evidence obtained then captured immediately
- [ ] Date and time visible on each capture
- [ ] Content of the evidence checked to be readable
- [ ] Evidence stored per objective

## Backups
- [ ] Notes backed up after each completed objective
- [ ] Copy of the folder kept off the workstation
- [ ] Journal up to date with the time of each step

## Report
- [ ] Report structure follows the examiner instructions
- [ ] Each completed objective described so a competent reader can repeat it
- [ ] Captures numbered and cited in the text
- [ ] Objectives not reached mentioned with what was tried
- [ ] File format and name checked
- [ ] File checksum recorded before sending
- [ ] Delivery confirmed before the deadline

## After the exam
- [ ] Access to the exam environment closed
- [ ] Exam data deleted according to the rules
- [ ] Engagement status updated
