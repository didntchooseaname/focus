# Keyboard shortcuts

Shortcuts by place. The same list, with the shortcuts you have changed, is in Settings, section Shortcuts. Back to [[index|Help]].

## Everywhere

| Shortcut | Action |
|---|---|
| Ctrl K, Ctrl P, Ctrl O | open the palette |
| Ctrl Shift P | open the palette on commands |
| Ctrl , | open the settings |
| Ctrl B | show or hide the left bar |
| Ctrl Alt B | show or hide the right bar |
| Ctrl J | show or hide the bottom panel |
| Ctrl Shift F | open the search panel |
| Ctrl Shift E | open the file tree |
| Ctrl E | switch between editing and reading |
| Ctrl W | close the tab |
| Ctrl Tab, Ctrl Shift Tab | next tab, previous tab |
| Ctrl \ | split right: the note goes to the other group of tabs |
| Alt Left, Alt Right | back, forward in the navigation history |
| Escape | close the open menu, palette or dialog |

## Palette and lists

| Shortcut | Action |
|---|---|
| Up, Down | move in the list |
| Enter | open |
| Ctrl Enter | open in a new tab |
| Escape | close |

## Source editor

| Shortcut | Action |
|---|---|
| Ctrl B | bold |
| Ctrl I | italic |
| Ctrl Shift X | strikethrough |
| Ctrl Shift C | inline code |
| Ctrl Shift K | link |
| Ctrl Shift H | heading |
| Ctrl Shift 8 | bulleted list |
| Ctrl L | task list |
| `/` | slash menu, see [[slash-menu\|The slash menu]] |

In the source editor Ctrl B is bold; elsewhere it toggles the left bar.

## Live view

| Shortcut | Action |
|---|---|
| Ctrl Shift M | open the Markdown source of the block that holds the caret |

## Search panel

The panel has its own shortcuts while it has the focus. The operators are in [[search-syntax|Search syntax]].

| Shortcut | Action |
|---|---|
| Up, Down, Page Up, Page Down | move between results |
| Enter | open the selected result at its line; with no selection and AI on, ask the assistant; with AI off, open the first result |
| Ctrl Enter | open in a new tab |
| Escape | clear the field, then give the focus back |
| Alt C, Alt W, Alt R | match case, whole word, regular expression |
| Alt S | next sort order |
| Alt H | show or hide the syntax help |
| Alt A | turn assisted search on or off |
| Ctrl Shift H | show or hide the replace field |
| Alt T | in a replace preview, keep or skip the selected note or line |

## Reading view

| Shortcut | Action |
|---|---|
| Ctrl C | copy the selected text |
| Ctrl A | select the whole note |
| Click on a link | open the target |
| Ctrl click on a link | open the target in a new tab |

## Graph

| Shortcut | Action |
|---|---|
| Arrow keys | pan |
| `+`, `-` | zoom in, zoom out |
| `0` | fit the whole graph in the view |
| Escape | clear the selected node |
