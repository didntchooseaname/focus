# Engagement workflow

## Scoping and authorization
- [x] Engagement letter or written agreement received and archived
- [x] Objectives restated and validated with the client
- [x] Rules of engagement read: hours, forbidden actions, emergency contacts
- [x] Person to notify in case of an incident identified, and a way to reach them tested
- [x] Data retention and destruction agreed

## Scope
- [x] List of included items received in writing
- [x] List of excluded items received in writing
- [x] Ownership of the items checked with the client
- [x] Third parties involved (host, provider) identified and notified if needed
- [x] Scope copied into the README of the engagement

## Collection
- [x] Information sources listed before starting
- [x] Each observation recorded in the journal with its target
- [x] Discovered items matched to the scope: inside, outside or to confirm
- [x] Questions for the client noted and sent

## Analysis
- [x] Candidate findings listed with the observations that support them
- [x] Each finding confirmed, or marked as to confirm
- [x] Severity and score vector justified
- [x] Affected items attached to each finding

## Evidence and timestamps
- [x] One piece of evidence per finding, readable without verbal explanation
- [ ] Date and time visible on each piece of evidence or tied to the journal
- [ ] Evidence stored in the engagement folder under stable names
- [ ] Sensitive data masked in the screenshots meant for the report
- [ ] Engagement folder backed up

## Cleanup
- [ ] Items created during the engagement listed
- [ ] Created items removed, or handed to the client with the list
- [ ] Temporary access closed
- [ ] Client data gone from the workstations once the engagement is closed

## Debrief and report
- [ ] Executive summary written
- [ ] Findings sorted by severity
- [ ] Recommendations written for each finding
- [ ] Review by a second person
- [ ] Report delivered through an agreed channel
- [ ] Debrief meeting scheduled
- [ ] Engagement status set to done
