# Report glossary

Terms used in our reports, with the meaning we give them. When a term appears in a client deliverable and may be unfamiliar, add it to the glossary appendix.

| Term | Meaning |
| --- | --- |
| Finding | One issue with a title, rating, evidence and fix |
| Observation | A note that has no rating but is worth knowing |
| Scope | The systems and dates the client authorised |
| Vector string | Compact text form of CVSS metrics, see [[CVSS 3.1 metrics]] |
| CWE | Class of weakness, see [[Common weakness enumeration]] |
| Retest | A later check that a fix works, see [[Retest planning]] |
| Remediation | The change that removes the weakness |
| Rules of engagement | Agreed limits on how testing is done, see [[Rules of engagement]] |

## Style

- One sentence per definition where possible.
- Use the same spelling as in the findings.
- Do not define a term with itself.

## Maintenance

Review the table when a report is closed. Terms that were confusing for the client go in first. The structure of the findings that use these words is in [[Finding template]].

> [!info] Abbreviations
> CIA stands for confidentiality, integrity and availability. It appears in the impact metrics of [[CVSS 3.1 metrics]].
