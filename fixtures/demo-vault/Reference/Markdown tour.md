# Markdown tour

A short tour of the syntax used across the vault. See also [[Callouts]], [[Tables]] and [[Note naming]].

## Headings

Six levels exist. Notes use levels 1 to 3.

### Emphasis

*Italic*, **bold**, ***both***, ~~struck~~ and `inline code`. A ==highlighted phrase== marks what to review.

### Lists

- First item
  - Nested item
- Second item

1. Step one
2. Step two

- [x] Done task
- [ ] Open task

## Quote

> Evidence first, opinion second.
> A finding without proof is a rumor.
