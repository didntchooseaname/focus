# Exam preparation plan

A plan for the weeks before a practical penetration testing exam. Check the vendor's own page for the current format, length and rules, since they change.

## Phases

| Weeks | Focus |
| --- | --- |
| 1 to 4 | Fill gaps from [[Study topics]] |
| 5 to 8 | Lab practice and notes, see [[Lab log]] |
| 9 | Full practice run, see the [Practice exam](Engagements/Practice%20exam/README.md) |
| 10 | Rest, logistics, review of [[Exam rules recap]] |

## Weekly rhythm

- [x] Pick two topics and write a short summary of each
- [x] Do a timed lab session
- [ ] Update the lab log the same day
- [ ] Review the notes from the previous week

## Habits

- Fixed study hours, same time each day.
- Notes written as if for a teammate, following [[Note-taking for exams]].
- One practice report before the real one, see [[Exam report]].

> [!tip] Plan the last week
> Do not start new material in the final days. Re-read your own notes and test your setup.

Time boxes are explained in [[Time management]].
