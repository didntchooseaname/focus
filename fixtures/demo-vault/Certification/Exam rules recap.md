# Exam rules recap

Rules differ for every exam and change over time. This note is a prompt for what to check, not a statement of any vendor's rules. Read the vendor's current page and candidate guide.

## Questions to answer

- [ ] How long is the exam and when does the clock start?
- [ ] Which tools and automated features are limited?
- [ ] Is outside material or a personal vault allowed?
- [ ] What is the proctoring setup and what must the room look like?
- [ ] What is the deadline and format of the report?
- [ ] What happens if the connection drops?

## Where to record answers

Copy the answers with the date and a link to the vendor page. Facts without a source go stale quickly.

> [!warning] When in doubt, ask
> If a rule is unclear, ask the vendor's support in writing before the exam. Keep the reply with these notes.
