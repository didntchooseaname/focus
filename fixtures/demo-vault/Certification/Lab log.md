# Lab log

A dated list of practice sessions, kept short. It shows which topics are solid and which are not.

## Entry format

```yaml
date: 2026-10-14
lab: internal training range
duration_min: 120
topic: web authentication
result: partial
next: repeat with fresh notes
```

## Using the log

- Review it every Sunday and pick topics for next week from [[Study topics]].
- A topic marked partial twice gets a dedicated session.
- Evidence from labs follows the same habits as client work, see [[Evidence handling]].

> [!info] Safe targets only
> Use ranges built for training, such as the [Practice exam](Engagements/Practice%20exam/README.md) or your own virtual machines.
