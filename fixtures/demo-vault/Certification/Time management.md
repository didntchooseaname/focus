# Time management

In a timed exam the scarce resource is attention. A visible budget stops you from sinking hours into one dead end.

## Time boxes

1. Give each target a first box, for example 90 minutes.
2. When the box ends, write what you tried and move on.
3. Come back after the first pass with fresh eyes.

> [!tip] Say it aloud
> Write the box start time in the notes. At the end of the box, the note itself tells you to stop.

## Tracking

Keep a running log with timestamps. The same habit is used during client work, see [[Time tracking]].

```text
10:05  start target A, port scan
10:40  web service found, notes in Study topics
11:35  box over, moved to target B
```

## Common traps

- Chasing one idea for hours.
- Forgetting evidence while rushing.
- Not eating.
