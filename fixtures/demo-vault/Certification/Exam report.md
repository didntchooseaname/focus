# Exam report

The exam report is a normal penetration test report in small. The vendor defines the required sections and the delivery format. Check that page first.

## Typical sections

| Section | Content |
| --- | --- |
| Overview | Scope, dates, summary of results |
| Per target | Findings with evidence |
| Appendix | Tools and versions used |

## Writing

- One finding per issue, following [[Finding template]].
- Evidence labelled and in order, with captions.
- Remediation written as in [[Remediation wording]].

## Checks before submission

- [ ] Every claim has a screenshot or output
- [ ] File name and format match the vendor's instructions
- [ ] Spelling and dates reviewed, as in [[Report review]]
- [ ] Notes from [[Note-taking for exams]] cross-checked

> [!question] How long?
> Length depends on the vendor. Do not pad. Clear and short beats long and vague.

A dry run with a practice target is described in [[Exam preparation plan]].
