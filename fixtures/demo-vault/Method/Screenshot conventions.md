# Screenshot conventions

A screenshot answers one question. If it needs a paragraph of explanation, crop it.

## Naming

Use the pattern from [[Note naming]]: date, target, subject.

- `2026-10-07-portal-login.png`
- `2026-10-08-fileserver-share-list.png`

## What to include

- The address bar or the terminal prompt, so the target is visible
- The time, when the clock is on screen
- A box around the relevant line, in one colour only

## What to leave out

- Passwords, tokens and session cookies
- Names of private individuals, unless the finding is about them

## Examples

Good: cropped to the result, one box, masked token. Poor: full desktop, many arrows, visible token.

> [!note]
> The file is stored as described in [[Evidence handling]]. In the report it gets a caption, see [[Writing a finding]].
