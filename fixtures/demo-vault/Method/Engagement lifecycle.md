# Engagement lifecycle

Every engagement follows the same six phases. The phase decides which notes we open and which we close.

## Phases

1. Scoping: [[Scoping call checklist]], then [[Scope table]].
2. Paperwork: [[Rules of engagement]] and the [[Authorization letter]].
3. Kickoff: [[Kickoff meeting]] with the client contact.
4. Testing: [[Journal keeping]], [[Evidence handling]], [[Daily wrap-up]].
5. Reporting: [[Finding template]] and [[Report review]].
6. Closing: [[Cleanup and handover]], then [[Retest planning]].

## Gates

> [!warning] No testing before both documents are signed
> The authorization letter and the rules of engagement must be filed in the engagement folder before the first packet leaves our machines.

- [x] Scope table agreed
- [x] Authorization letter signed
- [ ] Kickoff held
- [ ] Report delivered
