# Note naming

Names are short, in sentence case and readable without the folder. Links use the file name, so the name must stay stable.

## Rules

1. Notes are named after what they say: `Scope table`, not `scope_v3_final`.
2. Dated files start with an ISO date: `2026-10-07-portal-login.png`.
3. No slashes, colons or question marks in names.
4. One engagement, one folder, one `README` note.
5. Rename with the application so links follow.

## Examples

| Kind | Name |
|------|------|
| Method note | `Rules of engagement` |
| Journal | `Journal 2026-10` |
| Evidence file | `2026-10-08-fileserver-share-list.png` |
| Meeting | `Meeting 2026-11-02 team sync` |
